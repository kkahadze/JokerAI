# Historical experiments

These notebooks are preserved as research history. They target the pre-0.1 engine
and are not supported runnable examples. Their old output, timings and exception
tracebacks have been cleared. They are excluded from the installed package.

Use `examples/rollout.py` or `jokerai --games 10 --seed 42` for the supported,
reproducible API. The old notebook model is not used by either baseline agent;
see [artifact recovery](../docs/legacy-artifacts.md).
